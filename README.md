## 📖 Overview

**Kadadi Motors** is a next-generation digital insurance platform designed to modernize the way customers discover, compare, purchase, and manage vehicle insurance.

Instead of functioning as a traditional dealership website, Kadadi Motors delivers a complete insurance ecosystem featuring premium estimation, policy comparison, claim assistance, document management, emergency services, rewards, and customer support in a seamless user experience.

The platform emphasizes simplicity, speed, transparency, and accessibility while maintaining a premium interface suitable for modern insurance businesses.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/AMOGHKADADI/Kadadi-Motors.git
```

## Navigate

```bash
cd Kadadi-Motors
```

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

# 📈 Why This Project?

The insurance industry often suffers from fragmented customer experiences and outdated workflows.

The project demonstrates modern frontend architecture, reusable component design, scalable project organization, and a strong product-oriented development approach.
